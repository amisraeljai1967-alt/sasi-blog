# SASI Blog — primera versión

Landing editorial responsive para SASI | Innovación Bariátrica.

## Archivos
- `index.html`: contenido y estructura.
- `styles.css`: estilos y diseño responsive.
- `script.js`: menú móvil y año del footer.
- `assets/dr-rumbaut.jpg`: colocar aquí la fotografía oficial autorizada del doctor.

## Publicar con GitHub Pages
1. Crea un repositorio en GitHub (por ejemplo `sasi-blog`).
2. Sube todos los archivos y carpetas manteniendo la estructura.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona `Deploy from a branch`.
5. Selecciona `main` y `/ (root)`, y guarda.
6. GitHub te mostrará la URL publicada.
